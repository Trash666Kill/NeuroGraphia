🚀 Funcionalidades

    Deskew Adaptativo: Correção automática de orientação em dois estágios (cardinal e fino) via Transformada de Hough para garantir que as linhas de texto estejam perfeitamente horizontais.

    Segmentação Inteligente: Implementação do framework Kraken para binarização e segmentação de linhas com alta precisão.

    OCR de Alta Performance: Utiliza modelos TrOCR (Transformer-based Optical Character Recognition) da Microsoft, pré-treinados para caligrafia humana.

    Otimização para CPU: Suporte nativo à quantização INT8, permitindo execução rápida mesmo em máquinas sem GPU dedicada.

    Processamento em Lote: Interface CLI robusta para processar pastas inteiras de documentos de forma automatizada.
